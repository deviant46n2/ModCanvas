## Errata (2026-08-16, s66)

- **A2's "never committed" claim was WRONG.** The audit asserted featureparity.md
  "was NEVER committed — the doc has no history at all." `git log --follow`
  contradicts this: the file was first committed `b69edd3` (2026-08-01) and had
  four commits of history, including `931d7a1` (s64, 2026-08-15) which updated
  its §16 rows in-pass. The audit's error: the reference checks ran against a
  path that never existed (or an uncommitted assumption), while the file lived
  at repo root all along.
- **The decision stood but the execution lagged:** references were removed in
  the audit, but the file itself survived until s66, when the maintainer ruled
  it deleted as a completed todolist. Its §16 visual-parity rows were migrated
  to `docs/quest-editor.md` (Chapter-Open View Fidelity) before deletion.
- **Lesson (the s48 class, again):** a confident doc claim ("never committed")
  outlived the repo's actual state. The check that would have caught it —
  `git log -- <file>` at the root path — was never run against the right path.
