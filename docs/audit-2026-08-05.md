### H2. Comment preservation breaks on live export paths

The SNBT sidecar mechanism (import → export round-trip) works, but both live export
entry points pass an **empty sidecar**, silently dropping all user comments:

- `commands/modpack.rs:1249` — `export_ftb_quests_to_dir` (called by
  `useQuestToolbarActions.ts:135`).
- `commands/progression.rs:337` — `write_quest_graph_to_instance`.

`data.snbt`, `chapter_groups.snbt`, and `reward_tables/*.snbt` are always rebuilt
from the model without sidecar merge (`export.rs:146,278,322`).

### H3. Legacy data-URL texture scan still live

`icons.rs::scan_jar_for_textures` (icons.rs:96-99, indexer.rs:149-153) reads PNG
bytes during a scan and base64-encodes them to data URLs, persisting them to
`~/.cache/modcanvas/textures_<hash>.json` (icons.rs:165-213). AGENTS.md bans this
format ("Do not add new versions of the old data-URL index format"). Still called as
the no-instance fallback (`QuestBookEditor.tsx:401`,
`useQuestToolbarActions.ts:177,238`, `book-settings.tsx`).

### H4. Windows two-tier write pipeline absent

Standard (`AGENTS.md`): *"Windows writes MUST account for JVM file locks (EBUSY).
Always use a two-tier pipeline (Local IPC Socket bridge to the in-game mod -> Staged
.tmp disk sync fallback)."* The EBUSY retry loop exists and is correct
(`path_safety.rs:160-174`), but the IPC-socket-first pipeline and any
`#[cfg(windows)]` write path are absent.

## Medium severity

### M1. `core/theme/asset-cache.ts` breaks the pure core layer

Uses `localStorage` at :173/:179 and is a stateful singleton/observer
(`AssetCacheManager` with listeners, `globalAssetCache` export) — browser-global
side effects in the layer that must be environment-free.

### M2. `/src/drivers/` does not exist

`services/` fills the I/O-driver role (100% of `invoke()` calls), but the documented
`drivers/` directory is absent. Components import `services/*` directly, bypassing
the hook layer: `QuestBookEditor.tsx:3`, `App.tsx:12`, `RecipeEditor.tsx:15`,
`QuestCanvas.tsx:19`.

### M3. Path bugs on write paths

- `write_quest_graph_to_instance` double-nests: passes `…/config/ftbquests/quests`
  as `output_dir` while `export.rs:94` re-appends `config/ftbquests/quests`
  (`progression.rs:331`). Dormant (command not wired to UI) but wrong.
- `export_ftb_quests_to_dir` writes to an arbitrary user-supplied dir with no
  `validate_under_root` scoping (`commands/modpack.rs:1242-1251`).

### M4. TOML structured save loses comments

`save_structured_config` → `config_value_to_string` rebuilds the document from a
fresh `DocumentMut::new()` (`config_parser.rs:416-426`). Only per-value suffix decor
comments survive (`config_parser.rs:436-496`). Table headers, block comments, and
layout are lost.

### M5. `getSNBTSpec().dataComponents` dead in production

Defined on the interface and tested (`matrix.test.ts:99-131`) but never queried at
runtime. The "query Data Component support at runtime rather than hardcoding version
strings" intent is only half-realized — no hardcoded version strings, but no
adapter-driven gate either.

### M6. SNBT integral floats emit `1f` not `1.0f`

`snbt.rs:167` — `Float` emits `format!("{}f", v)`. Valid FTB SNBT and suffix/type
preserved, but not byte-identical to FTB output (affects `empty_weight` etc.).

## Passing areas

- **Atomic write primitive** — `path_safety.rs:138-177` tmp+rename, EBUSY retry
  loop at :160-174.
- **Adapter matrix** — directory layout, per-file isolation, 3-tier fallback
  resolution, `matrix.test.ts` coverage all pass.
- **Smart-filter DSL + icon_scale** — nested `ftbfiltersystem:filter` components +
  icon_scale written in both flat and subdirs layouts.
- **Quoted-colon SNBT keys** — `needs_quoting` returns true on `:`.
- **Number suffixes** — full typed model (Byte/Short/Int/Long/Float/Double)
  round-trips, EXCEPT parked holes (s23 proptest): f32 `-0.0` and integral ≥
  2^63 emit output the parser cannot re-read; trailing comments in nested
  compounds emit at the wrong indent; `needs_quoting` lets digit/-/./+/−-keys
  through the tokenizer mis-reads. See `src-tauri/src/imports/snbt_roundtrip.rs`
  header.
- **No game assets in bundle** — `frontend/public/` only self-authored icons; no
  `bundle.resources`; banned `theme/ftbquests/` removed.
- **Lazy materialization core** — `CACHE_VERSION=8`, descriptor-only disk cache,
  `resolve_texture_urls` batches per jar (BATCH_SIZE 500), skips `bake:` keys,
  `TAG_INDEX_MEMO` separate.
- **Offline-first** — no AI/LLM/telemetry SDKs; no network on any core path;
  WebSocket is the localhost companion bridge only.
