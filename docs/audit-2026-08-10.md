## The real finding: `bd4016b`'s false "zero behavior change"

`bd4016b` (00:28) split RecipeEditor.css into recipe-styles/ but the new
barrel imported the **old** paths (`./recipe-layout.css` instead of
`./recipe-styles/recipe-layout.css`). tsc does not resolve CSS imports, so
the break shipped silently — the app ran with **missing recipe styles for
~2.5 hours** until `accfab5` (02:51) repaired the barrel. The silent-
degradation class (s22), exactly what the state-truth suite exists for.

Two verdicts:
- `accfab5` is a forever fix **for the barrel** (correct paths, comment
  preserved).
- The root cause was parked since s30 as a tooling candidate and is now
  built: **`build-smoke`, the 9th integrity section** — runs the frontend's
  own `build` script (`tsc -b && vite build`) with `node_modules/.bin` on
  PATH (how pnpm actually resolves — a naive spawn produced a false
  violation, fixed before shipping). Violation on non-zero exit with the
  error tail; skippable via `rules.buildSmoke.skip`. 5 new suite tests
  (86 total). A refactor commit that cannot build is now a gate failure at
  commit time, not a 2.5-hour mystery.

## The distinction this audit teaches

- **Bandaid** = symptom masked at the wrong layer. Zero in the window.
- **Unlocked fix** = right layer, no regression net. Five, all closed here.
- **Unverifiable claim** = "zero behavior change" without a build to prove
  it. One, and it was false — now impossible to repeat.
