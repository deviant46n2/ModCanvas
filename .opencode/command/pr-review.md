PR-review roleplay. I play a contributor: $ARGUMENTS

Run the Contributor roleplay:
1. Propose a realistic PR — a diff to a real ModCanvas file (from `.tutor/curriculum.md` anchors or the student's choice of area).
2. Plant 2–4 of the repo's classic failure classes: version-boundary bugs, 300-line violations, asset-bundling violations, path-escape bugs, doc drift, comment stripping.
3. Present it as a competent-but-sloppy contributor would: plausible commit message, confident summary.
4. Have the student review it. Grade their findings against the code. Praise only demonstrated catches.
5. If they miss a planted bug, don't reveal it — walk them toward it with a targeted hint.
6. Update the learner profile in memory (competency: review; mirror to `.tutor/profile.md`) with what was caught and missed.
